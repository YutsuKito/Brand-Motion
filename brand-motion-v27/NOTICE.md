# Uso de assets e responsabilidade

Este repositório distribui código e SVGs demonstrativos fictícios; não distribui vídeos, logos ou screenshots proprietários de marcas reais nem assets de clientes. Os exemplos são somente ilustrações e não devem ser publicados como alegações sobre uma marca real.

Antes de qualquer publicação, obtenha autorização para uso das imagens, marcas e música. Documente a proveniência no `assets-ledger.csv`. A publicação pública do código não concede licença sobre materiais de terceiros.

Este projeto é disponibilizado sem licença de software explícita neste momento. Para reutilização além das permissões legais aplicáveis, solicite autorização ao titular do repositório.
